# Monopoly Game

### Демонстрация - https://drive.google.com/file/d/1ehzOHpUg5ETEltEKKfOYVf3uU-Ej7SZP/view?usp=sharing

## Описание проекта

Это реализация настольной игры Монополия на языке Java с использованием библиотеки Swing для графического интерфейса.
## Особенности игры

### Основные возможности:
- **Поддержка 2-4 игроков** - возможность выбора количества игроков в начале игры
- **Полноценное игровое поле** - 20 клеток с различными свойствами
- **Интерактивные кубики** 
- **Прогрессивная система аренды (аналог строительсва домов в оригинальной игре)** - стоимость аренды удваивается каждые 2 круга
- **Автоматический режим** - возможность наблюдать за автоматической игрой
- **Визуализация игроков** - цветные фишки игроков на поле

### Игровые механики:
- Покупка игровых полей(улиц)
- Оплата аренды при посещении чужой собственности
- Получение $200 при прохождении старта
- Система дублей (возможность повторного хода)
- Механизм банкротства

## Структура проекта

monopoly/  
--model/ # Модель данных игры  
---- Board.java # Игровое поле  
---- Dice.java # Игральные кубики  
---- Player.java # Игроки  
---- Square.java # Клетки поля  
---- Game.java # Игровая логика  
--view/ # GUI    
---- GameBoardPanel.java # Панель игрового поля  
---- ControlPanel.java # Панель управления  
---- PlayerInfoPanel.java # Информация об игроках  
---- InfoConsole.java # Консоль сообщений  
---- GameView.java # Главное окно  
--controller/ # Логика   
---- GameController.java # Игровая логика   
--MonopolyMain.java # Точка входа  

## Основные кнопки:
- Roll Dice - Бросить кубики и переместить фишку
- Buy - Купить текущую клетку (если она свободна)
- Pay Rent - Оплатить аренду владельцу клетки
- Next Turn - Передать ход следующему игроку
- Auto Game - Включить/выключить автоматическую игру
